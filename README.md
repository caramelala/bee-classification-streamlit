# Bee Classification App

Aplikasi ini dibuat menggunakan **Streamlit** untuk melakukan klasifikasi spesies lebah madu tanpa sengat berdasarkan gambar, menggunakan model CNN **VGG16** hasil training di Google Colab.


## Fitur
- Upload gambar lebah
- Prediksi kelas spesies
- Menampilkan probabilitas hasil prediksi
- Menggunakan model deep learning (.h5)
